# Blossom Link Saga (เกมเชื่อมดอกไม้ 20 ด่าน, PWA)

โปรเจกต์เกมแนวเชื่อมดอกไม้ สร้างด้วย HTML/CSS/JavaScript ล้วน ไม่ใช้ไลบรารี
กราฟิกดอกไม้และเสียงทั้งหมดสร้างด้วยโค้ด (Canvas / WebAudio) ไม่ใช้ภาพหรือเสียงของเกมต้นฉบับ

## โครงสร้างไฟล์
```
index.html              หน้าหลัก (หน้าเริ่ม / แผนที่ / หน้าเล่น / หน้าต่างผลลัพธ์)
manifest.webmanifest    ข้อมูลแอป PWA
sw.js                   Service Worker (แคช เล่นออฟไลน์ได้)
css/
  base.css              รีเซ็ต ปุ่ม และค่าพื้นฐาน
  title.css             หน้าเริ่มเกม
  map.css               แผนที่ ปุ่มด่าน ตัวละคร ผีเสื้อ
  game.css              หน้าเล่น แถบคะแนน ถาดไอเท็ม
  modal.css             หน้าต่างป๊อปอัป หน้าจบด่าน
js/
  core/store.js         เซฟความคืบหน้า/ไอเท็ม (localStorage)
  core/game.js          ตรรกะเกม: ลากเชื่อม ระเบิด ตกลงมา ไอเท็ม ชนะ/แพ้
  data/levels.js        ข้อมูล 20 ด่าน
  audio/audio.js        เสียงเอฟเฟกต์และเพลง (WebAudio)
  graphics/sprites.js   วาดดอกไม้ 5 ชนิด + ดอกบานใหญ่
  graphics/render.js    วาดกระดาน อนิเมชัน อนุภาค รับสัมผัส
  graphics/mapart.js    วาดฉากแผนที่ (ท้องฟ้า เนินเขา ต้นไม้ บ่อน้ำ ถนน กระท่อม)
  ui/ui.js              สลับหน้าจอ ป๊อปอัป เริ่มแอป PWA
  ui/map.js             สร้างแผนที่และปุ่มด่าน
  ui/hud.js             แถบคะแนน/ครั้ง/ดาว และหน้าแนะนำด่าน
  ui/result.js          หน้าจบด่าน (ชนะ/แพ้) และด่านถัดไป
icons/                  ไอคอนแอป
tools/build-preview.py  รวมเป็นไฟล์เดียวไว้ทดลองเล่น/แชร์ลิงก์
```
## วิธีเล่น
ลากเชื่อมดอกไม้สีเดียวกันตั้งแต่ 3 ดอก (ทแยงได้) เชื่อม 6 ดอกขึ้นไปจะได้ดอกบานใหญ่ ที่ระเบิดรอบตัวเมื่อถูกเชื่อมครั้งต่อไป
ไอเท็ม: พลั่ว, ระเบิด 3x3, สลับกระดาน, +5 ครั้ง (ชนะด่านรับเพิ่ม) ดาว 3 ระดับ = 1x / 1.4x / 1.8x ของเป้าคะแนน เมื่อได้ดาวดวงที่ 3 (และทำเป้าเก็บดอกไม้ครบ) จะขึ้นหน้าจบด่านพร้อมปุ่มไปด่านถัดไปทันที

## วิธีรัน (ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เพื่อให้ PWA ทำงาน)
`python3 -m http.server 8080` แล้วเปิด http://localhost:8080
ฝากบน GitHub Pages / Netlify / Vercel ได้ทันที (ต้องเป็น HTTPS เพื่อติดตั้งเป็นแอป)
